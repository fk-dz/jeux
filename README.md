# 🐍 أفعى نيون — Neon Viper

لعبة ثعبان سريعة تعمل في المتصفح: تحكّم دقيق للوحة المفاتيح واللمس، جسيمات،
اهتزاز شاشة، نظام كومبو، تفاحة ذهبية، وجدول أعلى النتائج محليًا.

## ⚠️ أي ملف تفتح؟

| الملف | النتيجة |
|---|---|
| `index.html` (الجذر) | ❌ نسخة المصدر — تعرض رسالة إرشادية وزر انتقال |
| `dist/index.html` | ✅ يعمل مباشرة |
| `docs/index.html` | ✅ يعمل مباشرة (وهو الملف المنشور على Pages) |

الناتج **ملف واحد مستقل بذاته** (كل JS وCSS مدمجون داخله) بفضل `vite-plugin-singlefile`.

## 🚀 النشر على GitHub Pages

### الطريقة الأولى: تلقائية عبر GitHub Actions (موصى بها)

1. ارفع المشروع إلى `main`.
2. **Settings → Pages → Build and deployment → Source** ← اختر **GitHub Actions**.
3. انتظر دقيقة، وستجد اللعبة على:
   `https://<المستخدم>.github.io/<المستودع>/`

> إن ظهر خطأ **404 File not found** بعد التغيير، افتح تبويب **Actions** وشغّل
> الـ workflow يدويًا بزر **Run workflow**.

### الطريقة الثانية: من مجلد `docs/` (بدون Actions)

المستودع يحتوي `docs/index.html` وهي نسخة مبنية جاهزة:

1. **Settings → Pages → Source** ← **Deploy from a branch**
2. **Branch** ← `main` · **Folder** ← `/docs` ← **Save**
3. انتظر دقيقة ثم أعد تحميل الصفحة.

> ⚠️ لا تختر `/ (root)` — فالجذر يحتوي `index.html` المصدرية و`dist/` غير مرفوع
> (مستثنى في `.gitignore`)، وهو سبب ظهور 404.

### تجديد `docs/` يدويًا

```bash
npm run build
node scripts/sync-docs.mjs
```

## 🛠️ التشغيل محليًا

```bash
npm install
npm run dev      # تطوير مباشر
npm run build    # ينتج dist/index.html
```

## 🧪 فحوصات

```bash
node scripts/check-boot.mjs    # 18 فحصًا: الإقلاع، البدء، الإيقاف المؤقت، الأخطاء
node scripts/check-paths.mjs   # استقلالية المسارات (ضروري لمجلد المستودع الفرعي)
node scripts/sync-docs.mjs     # مزامنة النسخة المبنية إلى docs/
```

## 🧩 الأنماط

- 🌀 **بلا حدود**: تعبر الحواف وتظهر من الجهة المقابلة.
- 🧱 **كلاسيكي**: الجدران قاتلة.

كل ٥ تفاحات تظهر ⭐ ذهبية تمنح ٦ أضعاف النقاط، والتقاط متتابع يبني كومبو حتى ×٨.

## 🔧 حل المشكلات

| المشكلة | السبب | الحل |
|---|---|---|
| `404 File not found` | Pages يخدم مجلدًا بلا `index.html` | اختر **GitHub Actions** أو **`/docs`** |
| رسالة «أنت تفتح نسخة المصدر» | فُتحت `index.html` الجذرية | افتح `dist/index.html` أو `docs/index.html` |
| صفحة بيضاء | نسخة قديمة من الملف المبني | `npm run build` ثم أعد التحميل |
| 404 على ملفات CSS/JS | لا يحدث — كل شيء مدمج | — |
| لا صوت | المتصفح يحجب الصوت قبل تفاعل | اضغط أي زر مرة واحدة |

اللعبة لا تحتاج سيرفرًا: الصوت مُولَّد بـ WebAudio، والرسم بـ Canvas، والنقاط في
`localStorage` عبر غلاف آمن لا ينهار في إطارات المعاينة المحجوبة.
