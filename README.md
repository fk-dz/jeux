# 🐍 أفعى نيون — Neon Viper

لعبة ثعبان سريعة تعمل في المتصفح، بتحكم دقيق للوحة المفاتيح واللمس، تأثيرات جسيمات،
اهتزاز شاشة، نظام كومبو، تفاحة ذهبية، وجدول أعلى النتائج محليًا.

## التشغيل محليًا

```bash
npm install
npm run dev      # وضع التطوير
npm run build    # ينتج dist/index.html
```

## ⚠️ مهم: أي ملف تفتح؟

| الملف | النتيجة |
|---|---|
| `index.html` (الجذر) | ❌ صفحة بيضاء — يطلب `/src/main.tsx` وهو TypeScript لا يفهمه المتصفح |
| `dist/index.html` | ✅ يعمل مباشرة — كل الـ JS والـ CSS مدمجان داخله (ملف واحد) |

البناء يستخدم `vite-plugin-singlefile`، لذا الناتج **ملف واحد مستقل بذاته**:

- لا يحتوي أي مسار مطلق (`/assets/...`) — يعمل من أي مجلد فرعي.
- لا يحتاج سيرفر — افتحه بنقرة مزدوجة أو ارفعه على أي استضافة ثابتة.

## النشر على GitHub Pages

الطريقة التلقائية (موصى بها):

1. ارفع المشروع إلى فرع `main`.
2. اذهب إلى **Settings → Pages**.
3. في **Source** اختر **GitHub Actions**.
4. سيبني الملف `.github/workflows/deploy.yml` المشروع وينشره تلقائيًا.

الرابط سيكون: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

### لماذا ستنجح هذه اللعبة على GitHub Pages تحديدًا؟

- **مسار مستقل**: لا توجد أي إشارة إلى `/assets/` في الناتج، لذا لا يهم أن تُخدم
  اللعبة من مجلد فرعي مثل `/my-repo/`.
- **`.nojekyll`** مضمّن في `public/` لمنع معالجة Jekyll.
- **أيقونة مدمجة** بصيغة `data:` — لا طلب إضافي ولا خطأ 404.
- **تخزين آمن**: كل وصول إلى `localStorage` مُغلَّف بـ `safeStore` مع بديل في الذاكرة،
  فلا تنهار اللعبة في إطارات المعاينة المحجوبة.
- **لا يحتاج سيرفر**: كل شيء يعمل في المتصفح (الصوت مُولَّد بـ WebAudio، والرسم بـ Canvas).

> ملاحظة: خطوط Google تُحمَّل من CDN خارجي، وإن تعذّر ذلك تستخدم الخطوط الاحتياطية
> تلقائيًا دون أي تأثير على اللعب.
