أنت تفتح نسخة المصدر.
هذا الملف (index.html في جذر المشروع) يطلب كود TypeScript لا يفهمه المتصفح مباشرة. الملف الجاهز للتشغيل هو dist/index.html.

للتشغيل محليًا شغّل npm run build ثم افتح dist/index.html — ملف واحد مستقل بذاته.
أو للتطوير المباشر: npm run dev.
وعلى GitHub Pages ارفع المشروع واختر Settings → Pages → GitHub Actions.
